# Rift Guardians — estado do serviço

Este repositório guarda o arquivo público `estado.json`, que o jogo Rift Guardians lê ao abrir para saber
o endereço do servidor, a versão mais recente e se há manutenção.

O arquivo é assinado: o jogo só aceita o conteúdo se a assinatura conferir com a chave pública gravada nele.
Alterar o arquivo à mão o invalida.

Responsável: Vitor Moura.
